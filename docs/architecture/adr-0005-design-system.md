# ADR-0005. Интерфейс: дизайн-система на токенах, единые компоненты, ECharts

- Статус: принято
- Дата: 2026-11-01
- Версия: 0.1.0

## Контекст

Страницы прежней версии оформлялись каждая по-своему: свои карточки показателей, свои фильтры, эмодзи вместо иконок, две библиотеки графиков (ECharts и Chart.js), шрифты с внешнего CDN (в закрытой сети не загружаются), длинные заголовки в верхней панели. Тёмная тема и палитра применялись не ко всем элементам.

## Решение

- **Токены** (`frontend/src/styles/tokens.css`): цвета поверхностей и текста для светлой и тёмной темы, шкала отступов, радиусы, тени, размеры шрифта; цвета светофора, бренда и серий графиков задаёт активная палитра (CSS-переменные). Тема — «светлая / тёмная / как в системе», применяется до отрисовки.
- **Шрифт** Inter Variable поставляется с приложением (`@fontsource-variable/inter`), числа — табличные.
- **Компоненты** (`frontend/src/components/ui`): заголовок страницы с действиями и свежестью данных, карточка показателя (значение, единица, светофор, изменение с оценкой по направлению, цель), карточка графика, панель фильтров, переключатель, модальное окно, подтверждение, уведомления, пустое состояние, загрузка файла с режимом «дополнить / заменить», настройка блоков дашборда, иконки (единый набор SVG).
- **Графики** — только ECharts с подключением нужных модулей (размер библиотеки в сборке уменьшился с 1037 до 579 КБ); тема графиков берётся из токенов и перерисовывается при смене темы и палитры.
- **Оболочка**: боковое меню по службам с уровнем доступа, хлебные крошки, «?» — переход к разделу руководства для текущей страницы, «Что нового» с отметкой непросмотренной версии.
- **Фильтры в адресной строке** (`useQueryState`): ссылкой на страницу можно поделиться вместе с фильтрами.
- **Встроенная справка**: руководства пользователя и администратора (`docs/manuals/*.md`) отображаются в приложении с оглавлением и поиском, PDF собирается из тех же файлов; история версий — из `docs/versions.md`.

## Последствия

- Новые экраны собираются из готовых компонентов и классов `base.css`; цвета в экранах задаются только переменными.
- Chart.js и внешние шрифты удалены из зависимостей.
