# Версии и release notes

Документ показывает историю версий в интерфейсе приложения («Что нового») простым пользовательским языком. Технические изменения для администраторов — в `docs/versions_admin.md`.

## Версия 0.1.0 (Ноябрь 2026 г.)

Первая версия «Дашбордов компании» как продукта: новый интерфейс, стартовая страница «Обзор», единые права доступа, встроенное руководство. Все данные прежней версии сохранены.

### Обзор

- новая стартовая страница: главное по каждой службе, к которой у вас есть доступ, — ключевые показатели, светофор «норма — внимание — критично» и когда обновлялись данные;
- последние загрузки файлов: кто и когда обновил отчёт техподдержки или заявки Naumen.

### Новый интерфейс

- единое оформление всех страниц: карточки показателей со светофором, изменением к прошлому периоду и целью, аккуратные графики и таблицы;
- тёмная тема — переключатель в верхней панели (светлая, тёмная или как в системе);
- меню по службам: в каждой службе — свои разделы, рядом указан ваш уровень доступа; меню можно свернуть;
- фильтры сохраняются в адресе страницы: ссылкой можно поделиться с коллегой, и он увидит то же самое;
- состав и порядок блоков дашборда настраиваются кнопкой «Настроить» и запоминаются для вашей учётной записи;
- страницы удобно открываются на ноутбуке, большом мониторе и телефоне.

### Служба персонала

- дашборд: приём и увольнение, текучесть с целью года, воронка найма, светофор по месяцам, разрез по подразделениям; выбор периода — быстрыми кнопками или по месяцам;
- приёмы и увольнения: поиск по ФИО и должности, фильтры, причина увольнения, выгрузка в Excel и PDF;
- ввод данных месяца: метрики по разделам, рядом — значение прошлого месяца; сохраняются только изменения, а при уходе со страницы без сохранения система предупредит;
- сводка по месяцам, кварталам, полугодиям и годам; цели и их выполнение; свои дашборды.

### Техническая поддержка

- дашборд недельного отчёта на новых графиках: светофор, динамика, трудозатраты по клиентам, AlterOS, AlterOffice, Project Server, каналы обращений;
- недельный отчёт: загрузка файла Excel или CSV — дополнить отчёт или заменить целиком; выгрузка в формате исходного отчёта;
- сравнение периодов, аналитика заявок Naumen, сопоставление отчёта с заявками Naumen;
- кнопка PDF на страницах техподдержки теперь формирует отчёты.

### Партнёрства

- у каждой записи реестра — свой светофор: учитываются статус, NDA, соглашение и срок сертификата; реестр можно отфильтровать по светофору;
- аналитика, сводка по годам и хронология сертификаций в новом оформлении; выгрузка реестра в Excel.

### Профиль и безопасность

- вход защищён лучше: после смены пароля остальные сессии завершаются; в профиле видно, где выполнен вход, и любую сессию можно завершить;
- временный пароль от администратора нужно сменить при первом входе; индикатор подскажет, насколько надёжен новый пароль;
- фото профиля, контакты и должность — в профиле.

### Справка

- руководство пользователя встроено в приложение: оглавление, поиск по тексту, скачивание PDF; значок «?» в верхней панели открывает раздел о текущей странице;
- «Что нового» — история версий; «О программе» — возможности и документация.

### Важно после обновления

- войдите заново: прежние сессии завершены;
- права доступа перенесены: «Начальник службы персонала» — теперь уровень «Управление» службой персонала, «Просмотр отдела» — «Просмотр» только своих подразделений.
