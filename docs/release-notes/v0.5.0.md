# 0.5.0 — «продуманность для читателя»

Реализация ядра плана 0.5.0 (docs/plans/v0.5.0.md; решения владельца зафиксированы 2026-11-21):
плотность смысла на первом экране. Схема базы, переменные окружения и настройки не меняются;
обновление — обычный `docker compose up -d --build`.

## Спарклайны

- `frontend/src/components/ui/SparkLine.vue`: мини-график 56×18 (svg) — ряд из ≤12 точек,
  null-пропуски сжаты по оси X, последняя точка окрашена по динамике (тон дельты).
- `/api/overview` теперь даёт `series` у КПИ: 12 месяцев (персонал) и 12 недель (техподдержка);
  ряд — от старых точек к новым. Партнёрства — счётчики состояния, ряда нет, спарклайна нет.
- Включён в `KpiCard` (дашборд персонала) и в ячейки КПИ «Обзора».

## Глоссарий показателей

- `frontend/src/components/ui/MetricGlossary.vue`: «?» у показателя → окно `AppModal`
  (Esc/фокус/`aria-modal` наследуются) с определением, единицей, направлением и пояснением
  «стрелка — динамика, значок — статус по порогам светофора».
- Источники описаний: справочник метрик персонала (`HrMetricDefinition.description`) и новые
  `COLUMN_DESCRIPTIONS` (`app/services/tp.py`), которые также отдаются в `/api/tp/columns`.
- Скрывается, если описания и направления нет — не шумит на пустых местах.

## Период на «Обзоре»

- Селектор месяца в шапке (список — `/api/reports/periods`): `?period=ГГГГ-ММ` в адресе;
  карточка персонала за выбранный месяц, «Сертификатов в {год}» и сквозная карточка следуют
  выбору; техподдержка — последняя неделя (подсказка селектора объясняет).
- Бэкенд: `GET /api/overview?period=` (422 на некорректном), кэш-ключ включает период; fallback —
  последний месяц с данными. Тест — `test_overview_period_sparklines_and_glossary`.
