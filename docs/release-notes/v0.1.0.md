# Release notes — v0.1.0

Ветка `v0.1.0` от `main`. Первая версия продукта «Дашборды компании»: прототип переработан целиком — сервер на зрелой платформе с PostgreSQL и миграциями, серверные сессии и единая модель доступа, новый интерфейс на дизайн-системе, стартовая страница «Обзор», встроенные руководства и история версий, тесты, CI и документация. Миграции `0012_v0_1_0_schema` и `0013_data_revisions`; данные прежней версии переносятся автоматически.

## Для сотрудников

- **Обзор** — новая стартовая страница: главные показатели каждой доступной службы, светофор, свежесть данных и последние загрузки файлов.
- **Новый интерфейс**: единые карточки показателей (значение, светофор, изменение к прошлому периоду с оценкой «лучше / хуже», цель), графики ECharts, таблицы с сортировкой, светлая и тёмная тема, сворачиваемое меню по службам с уровнем доступа, хлебные крошки, мобильная раскладка.
- **Фильтры в адресе страницы** — ссылкой можно поделиться; **«Настроить»** — состав и порядок блоков дашборда для своей учётной записи.
- **Служба персонала**: дашборд (приём и увольнение, текучесть с целью, воронка найма, светофор по месяцам, подразделения), реестр с поиском и выгрузками, ввод данных месяца с предупреждением о несохранённых изменениях, сводка по периодам, цели, свои дашборды.
- **Техническая поддержка**: дашборд недельного отчёта, загрузка и выгрузка отчёта, сравнение периодов, аналитика заявок Naumen, сопоставление отчёта с Naumen, PDF-отчёты.
- **Партнёрства**: светофор каждой записи и фильтр по нему, аналитика, сводка по годам, хронология.
- **Профиль**: фото, контакты, смена пароля с индикатором надёжности, уровни доступа, активные сессии.
- **Справка**: руководство в приложении (оглавление, поиск, PDF), «?» — раздел о текущей странице, «Что нового», «О программе».
- После обновления войдите заново: прежние сессии недействительны.

## Для администраторов

- **Пользователи**: карточка с профилем и **матрицей доступа к службам** («Просмотр», «Ввод данных», «Управление», «только свои подразделения» для службы персонала), временный пароль, отключение с завершением сессий; **подразделения**.
- **Роли**: «Администратор» и «Пользователь». Прежние роли перенесены в доступ к службе персонала: «Начальник службы персонала» → «Управление», «Просмотр отдела» → «Просмотр» своих подразделений.
- **Журнал изменений**: фильтры по пользователю, службе, объекту, действию и датам, значения «до» и «после», выгрузка CSV. Вход, смена и сброс пароля, загрузки файлов тоже в журнале.
- **Светофор** персонала и техподдержки — одна страница настройки с проверкой порогов; светофор партнёрств — правила категорий и сроки сертификата.
- **Загрузка файлов** с режимом «Дополнить» (по году и неделе / номеру заявки) или «Заменить» и журналом загрузок.
- **Палитры** с предпросмотром; **«О системе»**: версия, состояние схемы базы, объёмы данных, последняя загрузка.

## API

- Единый формат ошибок `{detail, code, fields}`; аутентификация — cookie `ds_session` + заголовок `X-CSRF-Token`; OpenAPI — `/api/docs`.
- Новое: `/api/overview`, `/api/services`, `/api/imports`, `/api/auth/sessions`, `/api/departments`, `/api/traffic-light/{service}`, `/api/layouts/{service}`, `/api/audit` (постранично) и `/api/audit/export.csv`, `/api/palettes`, `/api/system/info`, `/api/version`.
- Переименовано: `/api/hr/metric-definitions` → `/api/hr/metrics`, `/api/hr/benchmarks` → `/api/hr/targets`, `/api/hr/employees/{id}` → `/api/hr/events/{id}`, `/api/tp/rows` → `/api/tp/reports`, `/api/tp/export*` → `/api/tp/reports/export.{csv,xlsx}`, `/api/dashboard/preferences` → `/api/layouts`, `/api/palette` → `/api/palettes`, PDF — `/api/pdf/{служба}/{отчёт}`.
- Удалено: `/api/modules`, `/api/tp/rows/bulk_import`, JWT-токены.

## Развёртывание

- Docker-образ из корня репозитория; `docker-compose.yml` — приложение и PostgreSQL 16. Обязательны `SECRET_KEY` (32+ символа) и `POSTGRES_PASSWORD`.
- Миграции и справочники при старте (`python -m app.cli migrate`, под блокировкой PostgreSQL).
- Обновление прежних установок (SQLite в томе `db_data`): `docs/runbooks/upgrade-to-0.1.0.md`; перенос в PostgreSQL — `backend/scripts/sqlite_to_postgres.py`. **Перед обновлением сделайте копию базы** — откат миграции 0012 не поддерживается.
- Новые переменные: сессии, пароли, производительность, журнал — `docs/manuals/deployment-guide.md`, раздел «Переменные окружения».
- Нагрузочная проверка: 1000 одновременных пользователей на 4 ядрах — p50 12 мс, p95 46 мс, без ошибок сервера; при перегрузке — ответ 503 «Сервер перегружен» вместо зависания (`docs/performance/load-test-0.1.0.md`, ADR-0006).
