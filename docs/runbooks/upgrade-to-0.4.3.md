# Обновление до 0.4.3

Дисциплина вёрстки: каноническая лестница точек адаптива (640/960/1100/1280) и визуальные
регрессионные тесты. **Миграций нет** — схема базы не меняется; переменные и настройки — прежние.

## Порядок обновления

```bash
git fetch && git checkout v0.4.3
docker compose build
docker compose up -d
curl -s http://127.0.0.1:8000/api/health  # статус ok, версия 0.4.3
```

Обновление с 0.4.x — без промежуточных шагов.

## Проверка после обновления

- страницы открываются на телефоне/планшете как прежде (границы компоновки могли сдвинуться
  к ближайшей канонической точке: 560–720 → 640, 860–900 → 960, 1000–1200 → 1100);
- e2e в CI зелёные, включая новый проект `visual` (эталоны в
  `frontend/e2e/visual.spec.js-snapshots/`).

## Откат

`git checkout v0.4.2`, `APP_VERSION=0.4.2 docker compose up -d` — схема и данные совместимы.
