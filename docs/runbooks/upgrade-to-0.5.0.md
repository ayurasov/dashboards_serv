# Обновление до 0.5.0

«Продуманность для читателя»: спарклайны у показателей, глоссарий («?»), период на «Обзоре».
**Миграций нет** — схема базы не меняется; переменные окружения и настройки — прежние.

## Порядок обновления

```bash
git fetch && git checkout v0.5.0
docker compose build
docker compose up -d
curl -s http://127.0.0.1:8000/api/health  # статус ok, версия 0.5.0
```

Обновление с 0.4.x — без промежуточных шагов.

## Проверка после обновления

- «Обзор»: селектор «Период» в шапке; выбранный месяц меняет карточку персонала и сквозную
  карточку; у показателей — мини-графики и кнопка «?»;
- дашборд персонала: у ключевых показателей — спарклайн и «?»;
- `/api/overview?period=2026-06` — JSON с `series` и `about` у КПИ.

## Откат

`git checkout v0.4.3`, `APP_VERSION=0.4.3 docker compose up -d` — схема и данные совместимы.
