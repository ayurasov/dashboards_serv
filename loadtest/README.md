# Нагрузочная проверка

Сценарий Locust моделирует сотрудников, которые входят один раз и открывают страницы служб с паузой
на чтение 5–20 секунд: обзор и дашборды чаще всего, реестры и сводки реже, PDF и ввод данных — редко.
Каждая «страница» — тот же набор запросов API, что делает интерфейс.

```bash
pip install -r loadtest/requirements.txt
# сервер с демо-данными: DEMO_DATA=true, PostgreSQL, gunicorn (см. docs/performance/load-test-0.1.0.md)
./loadtest/run.sh http://127.0.0.1:8000 1000 6m
```

Критерий успеха (код выхода 0): доля ошибок не больше 1%, 95-й процентиль времени ответа не больше 1,5 с.
Результаты и методика 0.1.0 — `docs/performance/load-test-0.1.0.md`.
